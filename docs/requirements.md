# 簡単カンバン 要件定義書

作成日: 2026-11-10

## 1. 目的と背景

個人が自分のタスクを、列とカードで視覚的に管理できる、Trello風のWebアプリを作る。インストールやアカウント登録なしで、ブラウザだけで使えることを目指す。

- **背景**: 学習の一環として、要件定義から実装までの流れを経験する。実装は先行しており、この文書は実装した内容を整理して、要件として確定させるもの。
- **解決したいこと**: やることの状態（未着手・進行中・完了など）と期限が、一目で分かる状態にしたい。
- **方針**: 機能は簡単なものに絞る。複雑な機能は入れない。

## 2. 対象範囲

ブラウザ上で動く、ボード・列・カードの管理を対象にする。複数人での共同作業は対象外。

| 区分 | 内容 |
| --- | --- |
| 対象 | 1つのボード、列の追加・削除・並び替え、カードの追加・編集・削除・移動、カードの色と期限、ブラウザへの自動保存 |
| 対象外 | ログインとユーザー管理、複数ボード、複数人での同時編集、サーバーやクラウドへの保存、スマートフォン専用の操作、通知やリマインダー |

## 3. 利用者と利用場面

利用者は、自分のやることを整理したい個人1名。パソコンのブラウザで開いて使う。

| 場面 | やりたいこと |
| --- | --- |
| タスクを思いついた | カードをすぐに追加する |
| 作業を始めた・終えた | カードを別の列へドラッグで移す |
| 期限を管理したい | 期限を設定し、期限切れを赤字で確認する |
| 重要度や種類を分けたい | カードの色を変える |
| ボードの使い方を変えたい | 列の追加・名前変更・入れ替えをする |

## 4. 機能要件

必要な機能は13項目。ボード・列・カードの3つの対象に分けて整理した。「確認方法」は、要件を満たしたと判断する操作と期待される結果。

| ID | 対象 | 機能 | 要件の内容 | 確認方法 |
| --- | --- | --- | --- | --- |
| FR-01 | ボード | タイトル編集 | 画面上部のボードタイトルを自由に書き換えられる。空にすると「簡単カンバン」に戻り、ブラウザのタブ名にも反映される | タイトルを変更してリロードし、変更後の名前が残っている |
| FR-02 | 列 | 追加 | 「+ 列を追加」で列を追加できる。初期状態は3列で、見出しは「タイトル」と表示する | ボタンを押すと右端に新しい列ができる |
| FR-03 | 列 | 名前変更 | 列の見出しをクリックして自由に書き換えられる。空にすると「タイトル」に戻る | 見出しを変更してリロードし、名前が残っている |
| FR-04 | 列 | 削除 | 列見出し右の「×」で削除できる。カードが入っている列は、件数を示して確認する。削除すると中のカードも消える | カード付きの列で確認が出る。空の列は確認なしで消える |
| FR-05 | 列 | 入れ替え | 見出し左端の「⠿」をドラッグして、列の並び順を変えられる。挿入位置を線で示す。カードは列と一緒に動く | 列を入れ替えてリロードし、順番が残っている |
| FR-06 | カード | 追加 | 各列の下の入力欄にタイトルを入力して追加できる。空のタイトルでは追加できない | 入力して「追加」を押すと、その列の末尾にカードができる |
| FR-07 | カード | 編集 | カードをクリックするとダイアログが開き、タイトル・説明・期限を編集できる。タイトルは必須。保存とキャンセルを選べる | 編集して保存するとカードに反映される。キャンセルでは変わらない |
| FR-08 | カード | 削除 | カード右の「×」で削除できる。確認は出さない | 「×」を押すとカードが消える |
| FR-09 | カード | 列間の移動 | カードをドラッグ&ドロップして、別の列へ移せる | 別の列へ落とすと、カードがその列に移る |
| FR-10 | カード | 列内の並び替え | ドラッグ中に挿入位置を青い線で示し、同じ列でも別の列でも、好きな位置へ入れられる | 同じ列で順番を変えてリロードし、順番が残っている |
| FR-11 | カード | 色の変更 | カード上の丸ボタンを押すとパレットが開き、7色（白・赤・橙・黄・緑・青・紫）から選べる。選ぶとすぐ反映される | 色を選ぶとカードの背景が変わり、リロードしても残る |
| FR-12 | カード | 期限の設定 | タイトルの下に期限欄を常に表示する。欄をクリックするとカレンダーが開き、日付をクリックで選べる。期限が今日より前のカードは赤字にする | 日付を選ぶとその場で保存される。過去の日付で赤字になる |
| FR-13 | 全体 | 自動保存 | 操作のたびに、ボードの内容をブラウザに保存する。保存操作は不要 | 何か操作してリロードし、同じ状態で表示される |

## 5. データ要件

保存するデータは、ボード・列・カードの3種類。カードの並び順は保存順で、列の並び順は列一覧の順で表す。

| 種類 | 項目 | 内容 | 制約 |
| --- | --- | --- | --- |
| ボード | タイトル | ボードの名前 | 空不可。既定値は「簡単カンバン」 |
| 列 | ID | 列を識別する値 | 自動付与。重複不可 |
| 列 | タイトル | 列の見出し | 空不可。既定値は「タイトル」 |
| カード | ID | カードを識別する値 | 自動付与。重複不可 |
| カード | タイトル | カードの題名 | 必須 |
| カード | 説明 | 補足の文章 | 任意。改行可 |
| カード | 期限 | 期限日 | 任意。日付のみ（時刻なし） |
| カード | 色 | 背景色 | 7色から選択。既定値は白 |
| カード | 所属列 | カードが入っている列の ID | 列を削除するとカードも削除 |

## 6. 非機能要件

インストール不要で、ブラウザだけで動くことを最優先にする。

| 分類 | 要件 |
| --- | --- |
| 動作環境 | パソコンの最新版のブラウザ（Chrome、Edge など）。インターネット接続は不要 |
| 構成 | HTMLファイル1つで動作する。外部ライブラリやサーバーは使わない |
| データの保存 | ブラウザの保存領域（localStorage）を使う。ブラウザやタブを閉じても、パソコンを再起動しても内容は残る。保存はそのブラウザだけで有効で、別のパソコンや別のブラウザとは共有されない |
| 保存が使えないとき | プライベートウィンドウなどで保存できない場合も、エラーで止まらずに画面は動作する。ただしリロードで内容は消える |
| 操作性 | すべての操作を、1つの画面でマウスとキーボードだけで行える。読み込み後すぐ使え、保存操作を求めない |
| 表示言語 | 日本語 |
| データの安全性 | 削除を誤操作しやすい列の削除は確認を出す。カードの削除は確認なしで、元に戻す機能はない |

## 7. 制約と前提

- **利用者**: 1人だけが使う。同時に複数人が編集する状況は考えない。
- **保存先**: ブラウザの localStorage のみ。ブラウザのデータを消去すると、ボードの内容も消える。
- **端末**: パソコンのブラウザを想定する。ドラッグ&ドロップはマウス操作が前提で、スマートフォンのタッチ操作は確認していない。
- **データ量**: 個人のタスク管理に収まる量を想定する。大量のカードに対する動作は確認していない。
- **日付**: 期限切れの判定は、使っているパソコンの今日の日付を基準にする。

## 8. 今後の課題と未決事項

実装済みの機能では足りない点と、まだ決まっていない点を挙げる。優先順位は、利用者が決める。

| 項目 | 内容 | 決めたいこと |
| --- | --- | --- |
| カード削除の確認 | 今は確認なしで削除され、元に戻せない | 確認を出すか、元に戻す機能を付けるか |
| 完了カードの期限 | 期限が過ぎると、完了の列でも赤字になる | 完了したカードは赤字にしないか。列名を自由に変えられるので、判定の方法も決める必要がある |
| データのバックアップ | 保存先が1つのブラウザに限られる | ファイルへの書き出しと読み込みを付けるか |
| スマートフォン対応 | タッチ操作でのドラッグ&ドロップは未確認 | 対応するか、パソコンだけにするか |
| 編集ダイアログの期限欄 | カード上の期限欄と重複している | ダイアログ側の期限欄を外すか |
| 検索や絞り込み | 現在はない | 必要か。必要なら、タイトルや期限での絞り込みなど対象を決める |
